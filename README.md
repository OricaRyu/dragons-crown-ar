# The Dragon's Crown (AR Quest)

A short fantasy AR game that runs in a phone's web browser. Scan the QR code, allow camera and motion access, then:

1. Tap the treasure chests to find the golden key.
2. Tap the key to wake the dragon.
3. Turn around to follow the dragon and tap it 10 times to defeat it.
4. Claim the King's crown. The victory screen shows a QR code for sharing the game.
